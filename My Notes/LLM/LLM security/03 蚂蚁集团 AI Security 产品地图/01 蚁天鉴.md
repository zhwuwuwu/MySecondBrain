# 蚁天鉴

> 一句话：蚁天鉴是面向企业的大模型安全一体化解决方案，重点是对模型/应用进行安全检测，并提供相应的防御与治理能力。

## 1. 它是做什么的？

蚁天鉴不是一个单独的“安全模型”，而是一套企业级产品方案。公开资料将它描述为由 **蚁鉴**（检测）和 **天鉴**（防御）组成的大模型安全解决方案。

它关注的是上线前后的整体安全治理，例如：

- 检查模型和 AI 应用是否存在安全风险；
- 评估内容安全、模型鲁棒性和 AIGC 真伪；
- 对 Agent、MCP 等新型调用链进行安全扫描；
- 在应用运行过程中提供风险控制、零信任和治理能力。

## 2. 适合什么场景？

更适合组织级、企业级场景，而不是个人开发者给一个 Agent 加一层轻量拦截：

- 金融、医疗、政务等高合规行业上线 AI 助理；
- 企业在上线前评估模型、Agent 或完整 AI 应用；
- 对已有 AI 系统持续做安全检查、风险控制和审计；
- 需要统一管理多个模型、应用和 Agent 的安全团队。

公开资料提到的应用包括金融、医疗和政务场景。产品在 2023 年首次发布，之后迭代到 2.0，并增加了 Agent 安全评测、MCP 安全扫描等方向。

## 3. 它和另外三个产品是什么关系？

### 和 SingGuard

SingGuard 更像一个可被调用的多模态内容安全护栏模型；蚁天鉴更像企业检测、评估和治理平台。一个偏“安全判断能力”，一个偏“组织级产品方案”。理论上，SingGuard 可以作为某类内容或行为风险判断能力，接入更大的安全治理流程，但目前没有看到官方资料明确宣布二者的集成关系。

### 和 SingGuard-NSFA

SingGuard-NSFA 专门面向 Agent 行为安全；蚁天鉴也覆盖 Agent 安全评测和 MCP 扫描，因此两者在 Agent 安全方向有交集。但前者是开源护栏模型/框架，后者是企业级检测与防御方案，不能仅凭名称判断谁是另一者的下一代。

### 和 AgentAegis

AgentAegis 是针对特定 Agent 运行时的开源安全插件；蚁天鉴则是更高层的企业平台/方案。它们可能形成“平台评估与治理 + 运行时本地防护”的组合，但公开资料没有证明二者存在直接继承或官方组合关系。

## 4. 是否是谁的下一代？

目前没有足够的一手资料证明蚁天鉴是 SingGuard、SingGuard-NSFA 或 AgentAegis 的下一代。更稳妥的理解是：

> **蚁天鉴是企业级产品方案；另外三个更接近模型、Agent 护栏或运行时组件。它们处在不同产品层次。**
