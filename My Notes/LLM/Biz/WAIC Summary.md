# WAIC 2026 展会总结与战略分析

> 面向：人工智能企业战略团队、技术团队、VC 团队
>
> 时间：2026-07-17 至 2026-07-20；地点：上海；主题：**智能伙伴，共创未来**

## 证据标注

- **[A｜官方/组委会]**：WAIC/政府/公司官方资料，或媒体明确引述组委会。
- **[B｜明确报道]**：主流媒体、行业媒体或企业公开宣传明确关联 WAIC 2026。
- **[C｜待核]**：产品存在或出现在目录/单一报道，但缺少产品级现场证据。
- **[I｜分析]**：基于上述事实的行业判断，不是展会事实。

## 一、执行摘要

1. **从模型展示转向任务交付**：百度搭子、腾讯 WorkBuddy、南方电网“云睿”等把模型接入文件、网页、数据、电力规划等流程。[A/B]
2. **具身智能从整机演示转向数据闭环**：遥操作、数据手套、视触觉、仿真、评测和部署回流成为重要展陈方向。[B]
3. **算力从单芯片转向系统工程**：曙光 8000、真武 M890×磐久 AL128、中兴 OEX 等集中体现超节点、互联、内存和全链路能力。[A]
4. **大公司做平台闭环，初创公司做专业层**：前者覆盖芯片—云—模型—Agent—行业，后者集中于数据、仿真、传感器、灵巧手和垂直场景。[I]

> 核心判断：WAIC 2026 的竞争单位已经从单个模型转向“模型 + 数据 + 工具 + 终端/机器人 + 工作流 + 反馈闭环”。[I]

## 十二、技术团队与 VC 团队的判断框架

### 技术团队

- Agent：任务成功率、异常恢复、工具调用、权限审计、延迟、token 和人工接管成本。
- 机器人：连续运行时间、任务成功率、失败恢复、能耗、维护频率、负载和环境适应能力。
- 数据系统：采集同步、标注成本、仿真到现实迁移、真机评测和失败数据回流。

### VC 团队

| 维度 | 尽调问题 |
|---|---|
| 技术实质 | 是基础模型、控制器、数据硬件、集成方案还是单场景自动化？ |
| 商业 traction | 是否有付费客户、复购、持续运行和真实毛利？ |
| 数据壁垒 | 是否拥有真实任务数据和失败数据闭环？ |
| 生态位置 | 是否进入整机厂、大厂云生态或行业供应链？ |
| 规模化 | 项目制能否变成标准产品？交付和售后成本如何？ |

优先关注：灵巧手/触觉/力控、机器人数据与仿真、工业机器人、Agent 评测与安全、低成本推理和企业部署。[I]

谨慎对待：只有表演能力的人形机器人、只有聊天 Demo 的 Agent、只报参数不报成本的模型、只展示一次抓取且不披露失败率的机器人。[I]
