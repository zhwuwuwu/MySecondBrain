## 一、执行摘要：WAIC 2026 发生了什么变化？
WAIC 2026 的主题为：
	“智能伙伴，共创未来”
大会于 2026 年 7 月 17—20 日在上海举办。从公开报道看，本届展会最重要的变化不是“又发布了多少模型”，而是 AI 产业重心发生了三次迁移。
### 1. 从“模型展示”转向“任务交付”
往届展会常见的是：
- 模型参数规模
- benchmark 分数
- 多模态能力演示
- API 或聊天机器人
本届展会更强调：
- Agent 能否完成真实任务
- 是否能够调用工具、操作软件和设备
- 是否可以在企业流程中持续运行
- 是否有客户、订单和部署案例
也就是说，行业竞争从：
	“谁的模型更强”
逐渐变成：
	“谁能把模型变成可靠的工作系统”。
### 2. 具身智能从一个子赛道变成核心展区
本届具身智能与机器人被放在非常突出的位置，公开报道普遍认为：
- 人形机器人数量显著增加
- 机器人从静态展示变为动态交互
- 展示重点从“能走、能跳”转向“能干活”
- 灵巧手、机器人脑、世界模型、仿真和数据开始成为独立技术层
这意味着具身智能正在从单纯硬件创业，转向：
	本体 + 传感器 + 运动控制 + VLA/世界模型 + 数据闭环 + 场景交付
### 3. 算力叙事从单芯片转向系统工程
算力展区的重点不再只是：
- GPU 单卡峰值
- 芯片制程
- TOPS 数字
而更多讨论：
- 超节点
- 大规模集群
- 统一内存
- 网络互联
- 推理成本
- 集群利用率
- 国产软硬件生态
这反映出大模型产业已经进入“系统效率竞争”阶段。

### 2. Agent 的真正技术难点
展会宣传通常集中在 Demo，但技术团队应重点追问以下问题。
A. 任务是否能稳定完成？
需要关注：
- 成功率
- 重试次数
- 任务平均耗时
- 失败恢复能力
- 长任务中断后的恢复能力
B. Agent 是否能处理异常？
真实企业任务不会按照 Demo 路径运行，需要观察：
- API 失败怎么办
- 数据格式错误怎么办
- 权限不足怎么办
- 工具返回脏数据怎么办
- 用户临时修改目标怎么办
C. Agent 是否拥有长期记忆？
需要区分：
- 对话历史
- 临时摘要
- 用户偏好
- 企业知识
- 可审计的长期记忆
真正的 Agent 系统需要回答：
记忆是谁写入的？什么时候失效？如何纠正？如何删除？如何审计？
D. Agent 的成本是否可控？
Agent 不应只看单次调用价格，还要看：
单任务成本 =
模型输入成本
+ 输出成本
+ 工具调用成本
+ 检索成本
+ 重试成本
+ 人工兜底成本
### 3. WAIC 2026 大模型赛道的战略判断
#### 判断一：基础模型差异正在缩小，系统差异正在扩大
未来企业采购不会只问：
“你的模型 benchmark 多高？”
更可能问：
- 能不能接入我的系统？
- 能不能控制权限？
- 能不能留痕？
- 能不能稳定运行？
- 能不能部署到私有环境？
- 出错后谁负责？
这会降低单纯模型公司的议价能力，提高 Agent 平台、数据平台和行业解决方案的价值。
#### 判断二：Agent 进入“垂直流程重构期”
最有价值的 Agent 不是“聊天更自然”，而是重构一条业务链：
- 采购
- 销售
- 客服
- 研发
- 合规
- 财务
- 供应链
- 生产排程
VC 应关注那些已经拥有：
- 行业数据
- 工作流入口
- 企业客户
- 交付能力
- 反馈闭环
的团队，而不是仅有一个漂亮 Agent Demo 的团队。

## 五、“镇馆之宝”与代表性展品
### 1. 智元机器人：远征 A3 Ultra
目前公开报道中，智元机器人远征 A3 Ultra 是最明确、声量最高的具身智能“镇馆之宝”候选/入选展品。
媒体报道的关注点包括：
- 全尺寸人形机器人
- 面向商业化部署
- 机器人脑与本体结合
- 强调量产和真实工作场景
- 被描述为 WAIC 2026 具身智能领域的重要代表展品
其战略意义不只在于机器人外观或动作，而在于它代表了一种产业路径：
从“机器人研发样机”转向“可部署、可量产、可进入工作场所的产品”。
需要注意：公开资料中出现了不同参数和表述，技术团队不应在未获得产品白皮书前直接引用具体 TOPS、自由度、负载等数据。
### 2. 蚂蚁灵波：智慧药房方案
媒体报道将其描述为：
- 一脑多机
- 多种机器人本体共享同一套具身智能能力
- 在药房流程中完成配药任务
- 强调小空间部署和流程效率
它的价值在于验证：
具身智能是否可以从“通用机器人”转向“标准化工作单元”。
如果这类产品能够规模部署，商业模式可能不是卖机器人，而是：
- 按药房收费
- 按任务收费
- 按服务量收费
- 软硬件一体化订阅
### 3. “镇馆之宝”名单的证据边界
目前公开检索到的资料可以确认：
- WAIC 存在“镇馆之宝”评选/宣传机制
- 远征 A3 Ultra 被多家媒体重点报道
- 智慧药房方案也被报道为代表性展品
但目前不应把媒体文章中的完整十项名单直接当作官方最终名单。报告建议使用以下表述：
“公开媒体重点报道的代表性镇馆展品包括……；完整官方名单及评选标准仍应以 WAIC 主办方最终公告为准。”

7. “未来感”较强的机器马、机器狗和人形机器人  
8. 能够直接使用的消费级 AI 产品
公众对底层技术的关注相对较少，例如：
- 推理吞吐
- KV Cache
- 通信拓扑
- 模型蒸馏
- 训练数据效率
- 仿真迁移
这不意味着这些技术不重要，而是它们不容易形成大众传播内容。
#### 2. 微博
公开媒体和舆情监测材料显示，微博热度主要集中在：
- WAIC 现场机器人
- 机器马、机器狗、人形机器人
- Kimi 和其他大模型的发布动态
- WAIC 现场体验和排队
- 大会采购金额及产业合作消息
有报道提到：
- 某些机器人现场话题在榜时间较长
- “世界人工智能大会怎么逛”等攻略型内容获得较高传播
- Kimi 相关话题进入微博热搜
但这些属于：
- 特定时间窗口
- 爬虫或媒体监测样本
- 不是全周期、全平台统一排名
#### 3. Bilibili
Bilibili 上更容易形成传播的内容是：
- 机器人实机动作
- 机器人载人
- 人形机器人行走、跳舞、格斗
- 现场拆解和技术讲解
- 模型发布会片段
- 机器人与真人互动
B 站用户比微博用户更重视：
- 机器人动作是否自然
- 电池续航
- 关节结构
- 机器人稳定性
- 是否是遥控
- 是否具备真正自主能力
因此 Bilibili 舆论可以作为“技术质疑度”的观察窗口。
#### 4. 小红书
小红书的内容更偏向：
- 逛展攻略
- 打卡路线
- AI 眼镜体验
- 机器人拍照
- 展会排队和门票
- 可穿戴设备
- 适合拍摄和分享的展品
小红书关注的是：
“这个东西能不能让我体验、拍照、分享和带走？”
因此，小红书热度更适合判断消费级产品的传播潜力，不适合直接判断技术成熟度。
#### 5. 社媒热度如何转化为投资判断？
建议把“热度”拆成四种：
热度类型	含义	投资价值
视觉热度	好看、会动、容易拍视频	低到中
话题热度	名人、发布会、争议话题	中
技术热度	工程师讨论真实能力	中到高
交易热度	客户、订单、采购、部署	高
真正值得 VC 追踪的是第四类。

## 八、展区和公司聚集的结构性判断
虽然目前公开材料不足以严谨还原每家公司的最终展位坐标，但可以从产业链和展区定位判断出明显的聚集关系。
聚集一：大公司集中在“平台型基础设施”
包括：
- 芯片
- 云
- 模型
- 数据中心
- 企业服务
- 行业解决方案
它们会通过一个展位同时展示：
芯片 → 云 → 模型 → Agent → 行业应用
这是大公司的系统优势。
聚集二：机器人公司集中在“动态展演区”
机器人公司天然需要：
- 较大空间
- 安全隔离
- 动态表演
- 现场交互
- 真实物体操作
因此，机器人展区更容易形成高密度的产品对比。
聚集三：初创公司集中在“组件和专业化环节”
初创公司很少与大公司正面竞争通用模型，而是集中在：
- 灵巧手
- 运动控制
- 触觉
- 数据采集
- 仿真
- 垂直场景
- 低成本部署
这是更现实的产业切入点。
聚集四：模型公司和机器人公司开始交叉
本届最值得关注的产业融合是：
大模型公司
        +
机器人本体公司
        +
工业场景公司
        +
数据/仿真公司
未来的领先企业不一定是单独的模型厂商或机器人厂商，而可能是掌握完整闭环的组合型公司。
## 九、对技术团队的重点建议
1. 不要只评测模型，要评测任务系统
技术团队应建立以下测试：
- 多步骤任务成功率
- 工具调用准确率
- 长任务稳定性
- 失败恢复能力
- 记忆准确率
- 延迟和成本
- 人工接管比例
2. 建立机器人真实能力评测
不要只看：
- 会不会走
- 会不会跳
- 会不会说话
要看：
- 连续工作时间
- 任务成功率
- 失败恢复率
- 能耗
- 负载
- 维护频率
- 真实客户部署
- 环境变化适应能力
3. 重点追踪跨本体模型
具身智能最重要的技术问题之一是：
一个模型能否控制不同形态的机器人？
如果只能控制单一本体，它更像专用控制器；如果可以跨本体迁移，才更接近机器人基础模型。
4. 关注数据闭环，而不是一次性 Demo
应重点问：
- 数据从哪里来？
- 是否有真实任务数据？
- 是否能自动标注？
- 是否有失败样本？
- 数据是否回流训练？
- 数据是否能跨本体复用？
## 十、对 VC 团队的投资判断框架
建议对每家公司从四个维度打分。
维度	关键问题
技术实质	是否有不可替代技术？
商业 traction	是否有付费客户和复购？
生态位置	是否进入大厂、整机厂或行业供应链？
投资可行性	市场空间、毛利、规模化和退出路径如何？
最值得重点尽调的方向
第一优先级
- 机器人灵巧手
- 力控和触觉
- 机器人数据闭环
- 仿真和世界模型
- 工业场景机器人
- Agent 运行基础设施
- 企业级 Agent 安全和评测
第二优先级
- AI 眼镜
- 端侧模型
- 低成本推理
- 机器人操作系统
- 行业智能体
- 多模态交互
谨慎对待
- 只有表演能力的人形机器人
- 没有客户的通用 Agent
- 只强调参数、不披露成本的模型
- 只展示概念、不披露失败率的机器人
- 依赖单一大客户的项目公司
- 将集成方案包装为自研基础技术的公司
## 十一、WAIC 2026 的最终战略判断
判断一：AI 产业进入“系统竞争”
模型、芯片、Agent、机器人和行业流程正在组合成完整系统。
未来的竞争单位不是单个模型，而是：
模型
+ 数据
+ 工具
+ 工作流
+ 终端
+ 反馈闭环
+ 商业场景
判断二：具身智能的真正壁垒是数据和部署
硬件可以采购，模型可以合作，但以下资产更难复制：
- 真实任务数据
- 机器人失败数据
- 跨本体迁移能力
- 客户现场经验
- 维护和交付能力
- 机器人与工作流的深度融合
判断三：Agent 的价值取决于是否接管流程
“会聊天”不是壁垒，“会生成”也不是壁垒。
真正有价值的 Agent 必须能够：
- 读取企业数据
- 调用业务系统
- 完成多步骤任务
- 处理异常
- 接受审计
- 在成本可控的情况下持续运行
判断四：展会热度和产业价值之间存在明显差距
最容易上热搜的通常是：
- 人形机器人
- 机器狗
- AI 眼镜
- 载人机器人
- 有趣的交互 Demo
最可能产生长期商业价值的则可能是：
- 芯片和基础设施
- 机器人核心零部件
- 企业 Agent 平台
- 数据和仿真
- 工业自动化
- 安全、评测和运维系统
一句话结论
WAIC 2026 展示的不是“AI 已经成熟”，而是 AI 正从模型能力竞争进入由模型、Agent、机器人、算力和行业流程共同构成的系统工程竞争。
对于技术团队，最重要的是从 Demo 走向可重复评测；对于 VC 团队，最重要的是从展位热度走向客户、数据、部署和复购证据。
